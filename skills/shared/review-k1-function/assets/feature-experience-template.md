# 功能名称：验收经验档案

填写时保留真实未知项及下一步，删除本段使用说明。创建于 `<workspaceRoot>/.local/features/<featureId>/experience.md`，这是用户私有档案，不随共享 skill 分发；该功能的运行脚本及使用说明放在同目录下的 `scripts/`。路径相对实际档案目录解析；一个功能对应一个稳定 featureId 和目录。

| 字段 | 内容 |
|---|---|
| featureId | 项目与功能的稳定标识 |
| 名称 / 别名 | 正式名称、旧称、代码关键词 |
| 关联需求 / 分支 | 已核实的 Jira、需求标识和历史分支，仅作定位 |
| 档案更新时间 | 实际维护日期及时区 |
| 最近实际验证 | 日期、阶段、版本与来源；未知写未验证 |
| 维护源 / 在线地址 | 当前本地文件；未来迁移时填真实在线地址 |
