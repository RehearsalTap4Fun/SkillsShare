# 已学习流程的复用

用于同一功能中已实际走通的重复操作；与语义录制/回放共用本轮身份、版本、授权和证据台账。

先按 [功能索引](../features/index.md) 读取对应档案，并执行 [经验读写规则](feature-experience.md)。本页只保留跨功能的重复操作原则；新经验更新对应功能档案，必要脚本归档并登记使用说明。

## 学一次，后续按状态执行

- 首次成功时记录业务名、起止界面、语义入口/控件、异步完成条件、权限与资源参数、异常分支、版本和成功回执；不只保存屏幕坐标。
- 重复操作先查已有流程。客户端入口及界面结构仍兼容、身份及活动匹配时直接复用，不每次截图、重新找类名或重读同一源码。配置更新重新确认受影响参数，不能沿用旧价格、数量与目标。
- 导航检查页面生命周期；业务动作核对 Ack、适用的 Ntf、权威状态及资产差值。结果未知时只回读，不自动再次购买、升级、领奖或开始新局。
- 将同一流程的异步等待交给有时限的 MCP 状态机，不让模型在每个确定步骤之间重新决策。结束、身份/活动切换、编译重载、异常或超时都注销回调。
- 截图可后台采集，无需逐张分析。首次页面/结果、新元素/布局、异常、视觉断言及报告关键节点仍需实际看图；未知弹窗或结果矛盾时退回视觉检查。反馈表原问题图仍必须逐项查看。
- 流程不是授权缓存：购买逐次核对商品、当前展示价格、数量、限购和支付环境；GM 以本轮许可为准，旧 GM 授权不能带进正常玩家体验。
- 固定导航与游戏策略分开：下一关入口可复用，瞄准、障碍布局和道具选择仍依据当局可见信息，不能把旧角度套到新关卡。
- 记录调用次数、成功/超时/回退次数及耗时；只有实测数据才能声称提速。
- 已确认 API 记录签名、所属类型和可读 UI 文本组件，后续先用记录；不要对同一个已验证方法反复全文搜索。新 API 先确认字段/方法与参数类型，编译失败时保持关卡未开始或通过正常说明页暂停，不能边空耗倒计时边补工具。
