# 共享方法与私有经验

共享 skill 的 features 保存通用检查方法及参数化脚本。实际需求、身份、环境、提交、链接、证据和结论保存在使用者工作区；日常验收不自动写回共享目录。

## 位置

| 内容 | 位置 |
|---|---|
| 共享索引与指南 | [features/index.md](../features/index.md)、features/<featureId>/experience.md |
| 共享脚本模板 | features/<featureId>/scripts/，先读同目录 usage.md |
| 私有索引和档案 | `<workspaceRoot>/.local/features/index.md`、`<workspaceRoot>/.local/features/<featureId>/experience.md` |
| 本轮增量/恢复笔记 | `<workspaceRoot>/.tmp/<run-id>/experience-notes.md` |
| 实际计划、证据及报告 | 本轮 .tmp / reports，由计划关联，不随包分发 |

## 读取和维护

1. 按功能名与别名读取共享指南，再读用户提供的私有经验。featureId 稳定，不用需求编号、账号或批次代替。
2. 对比当前需求、三端版本、配置、接口、环境身份和权限。共享提示和历史结果不是本轮已验证结论；缺来源、版本不明或不兼容的条目先复核。
3. 每阶段及中断前，将新事实、采用/弃用方法、实际证据和下一步写入本轮笔记，再合入私有经验。首次使用 [档案模板](../assets/feature-experience-template.md)；无新增时记无新增。
4. 每条私有经验包含 entryId、方法/结论、适用条件、验证日期/层级、真实来源、状态和下一步。已验证/待验证/已失效分开；静态、编译、运行和业务验证分别记录。
5. 写前复读并保留他人增量，写后核对。无法写入时保留笔记并报告待回写；未知结果先核对，不重复业务操作来补记录。

经验不覆盖本轮需求，不扩大授权，不改变正式仓库只读约束。不能访问历史来源时说明缺口，不伪造链接或把示例标为已验证。

## 共享更新

推广经验需单独整理：去除真实文档/nodeId、群/机器人、SID/账号、私有提交/构建记录与证据路径，仅保留可复用方法和参数。删除公开历史前保留私有原件；脱敏指南不冒充原报告。

模板说明保留用途、依赖、全部参数/单位、开始条件、完成信号、副作用、停止/清理和恢复方法。每轮复制到自己的 .tmp，计算模板哈希，绑定身份与授权，检查占位符全部替换后执行。截图、完整回执、凭证、DownKey 和绑定后的脚本不进入共享包。
