# 冷库配置快照提取脚本



## 宿主、依赖和参数

宿主为本地 Python 3，使用 `json`、`hashlib`、`pathlib` 标准库及 `openpyxl.load_workbook`。原始运行未记录 Python/openpyxl 精确版本；本次合成测试为 Python 3.12.14、openpyxl 3.1.5。模板本身没有命令行参数解析：先复制到本轮 `.tmp/<run-id>/`，将下列字符串占位符全部替换，再由 Python 解释器执行该副本。不要在 Skill 唯一源中填入身份或路径。

| 必填占位符 | 类型 / 单位 | 绑定依据 |
|---|---|---|
| `__CONFIG_SNAPSHOT_DIRECTORY__` | 绝对目录字符串 | 本轮已取得、可只读核验的快照目录，内含 `ColdServer.xlsx`、`ConstConfig.xlsx`、`ActivityOnline.xlsx`；不使用正式仓库工作目录 |
| `__SOURCE_SERVER_ID__` | 十进制 SID 字符串，无单位 | 本轮来源服；只用于筛选离线行，不授权操作对应服 |
| `__TARGET_SERVER_B_ID__` | 十进制 SID 字符串 | 本轮目标 B |
| `__TARGET_SERVER_C_ID__` | 十进制 SID 字符串 | 本轮目标 C |
| `__ACTIVITY_TEMPLATE_ID__` | 十进制活动模板 ID 字符串 | 正式表模板 ID，不是运行活动实例 ID；历史值为 100003，当前必须复核 |
| `__OUTPUT_FILE__` | 绝对 JSON 文件路径字符串 | 本轮 `.tmp` 内不存在的新文件；父目录预先创建。`write_text` 会覆盖同名文件，模板没有防覆盖或自动建目录逻辑 |

路径建议用 `/`；替换值处于 Python 单引号字符串中，含引号/反斜杠时需正确转义。执行前检查没有 `__...__` 标记，确认六个值、输入文件和新输出路径。未替换的 SID 或模板 ID 可能只得到空命中而不报错，不能把“能运行”当参数正确。

固定依赖及限制：三表文件名、前 8 行表头、第 9 行起数据；`ConstConfig` 匹配 `10135787/10135788/10135790/10135791/冷库/冷冻`，活动表只在前四个单元格匹配模板 ID；冷库表在整行任一单元格匹配 SID。这是原始筛选方式，不是严格按主键查询。配置结构或键名变化时先复核这些条件。使用 `data_only=False` 会保留公式文本，不计算公式；空命中不能证明不存在相关配置。只导出三表，不涵盖邮件、平台配置或完整业务校验。


## 开始、结束与清理

开始状态：本轮离线快照已通过相应来源/版本校验，依赖已具备，快照只读，输出父目录可写。按 `config-table-editor` 的 K1 Excel 约定取得和确认工作簿；需要从冻结 Git/LFS 导出时引用唯一公共源 [export-git-file.ps1](../../../scripts/export-git-file.ps1)，按主 Skill 的缓存/权限规则执行，本模板不负责获取或推导版本。

调用方式为 `python -X utf8 <本轮已绑定参数的副本.py>`，路径含空格时按当前 shell 加引号。Windows 上 UTF-8 捕获 stdout 时要启用 `-X utf8`，否则中文摘要可能按系统编码输出；JSON 文件本身明确使用 UTF-8。

正常完成：解释器退出码 0、新 JSON 可解析，最外层三条记录均含 `file`、`sha256`、`sheets`；每个 sheet 含 `sheet/rows/headers/matches`，每个命中含 `row/values`。stdout 另给精简匹配摘要。将输出 hash 与输入快照、字段名、期望筛选行交叉核对；脚本完成不代表配置业务通过。

副作用仅为创建/覆盖指定 JSON 和标准输出；以 `read_only=True` 打开工作簿，不保存输入文件，无资产消耗、业务请求、定时器、回调或持久会话。输出含本机路径、表内容与历史定位信息，属于本轮证据，不回拷到 Skill。

停止方式：中止 Python 进程即可。无内置超时，原脚本将每张表的行转为列表，较大工作簿可能耗时或耗内存；本轮宿主应设置合适的执行超时。正常路径调用 `wb.close()`；异常或中止由进程退出释放句柄，先确认进程已结束。失败时保留 stderr、核对输出可能不存在/不完整；改用新的输出文件重试，不能覆盖旧证据。清理仅限本轮生成的副本和输出，按本轮留存要求处理，不改原表或历史报告。
